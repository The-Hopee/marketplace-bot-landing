Политика конфиденциальности

1. Какие данные мы собираем

При использовании Telegram-бота Finder мы получаем:

  • Telegram ID (уникальный идентификатор)
  • Имя пользователя, имя и фамилию (из профиля Telegram)
  • Поисковые запросы
  • Статистику использования бота (количество поисков)

2. Как мы используем данные

  • Для выполнения поисковых запросов
  • Для управления подпиской
  • Для формирования популярных запросов
  • Для обработки платежей

3. Платёжные данные

Оплата производится через платёжную систему Т-Банк. Мы НЕ храним данные банковских карт. Все платёжные данные обрабатываются Т-Банком в соответствии со стандартом PCI DSS.

4. Передача данных третьим лицам

Мы не передаём ваши персональные данные третьим лицам, за исключением:

  • Передача поисковых запросов в API маркетплейсов (Wildberries, OZON) для выполнения поиска — без привязки к личности пользователя
  • Случаев, предусмотренных законодательством РФ

5. Хранение данных

Данные хранятся на защищённых серверах. Поисковые запросы хранятся для формирования статистики и улучшения сервиса.

6. Удаление данных

Вы можете запросить удаление всех ваших данных, написав на email: timofej.derevaynkin@inbox.ru. Данные будут удалены в течение 30 дней.
